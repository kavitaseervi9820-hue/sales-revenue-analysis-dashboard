## Task

Automate data cleaning and reporting workflows. The Thiranex task asks for a solution using Python, Excel, or Power BI that handles missing values, duplicates, and inconsistent data, then generates automated reports and visual summaries.

## Planned workflow

1. Document the input data and fields.
2. Check for missing values, duplicate records, inconsistent formats, and invalid values.
3. Apply documented cleaning rules and preserve the original source data.
4. Generate a repeatable cleaned output.
5. Produce a report or visual summary and document how to run the workflow.
